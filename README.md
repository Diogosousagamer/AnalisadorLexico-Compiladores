# AnalisadorLexico-Compiladores
Este repositório apresenta uma implementação de um Analisador Léxico para uma versão simplificada do Pascal, servindo como parte da avaliação parcial da disciplina de Compiladores ministrada pelo professor José Carlos Martins Oliveira no VI Semestre 2026.2 do curso de Ciências da Computação da Universidade Estadual do Sudoeste da Bahia (UESB).
